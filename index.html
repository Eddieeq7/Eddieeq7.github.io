Selected work

Four projects, what each one actually does, and how.

  1. 01

    AEGIS Desktop

    Python · LLM agents · Windows internals · 2026

    A two-agent system that investigates why a Windows machine is slow, decides what to do about it, then checks whether it actually worked.

    • Deep Investigator — probes process memory-growth rate, thread counts, network connections, disk, GPU, driver health, page file, and Event Log errors in parallel over a 5-second behavioral window (~8–10s total).
    • Decision Engine — a three-phase loop: diagnose root cause first, plan tools with confidence scores, then re-probe and replan if the goal wasn't met.
    • The LLM is handed a different expert persona per intent — gaming specialist, performance diagnostician, storage specialist.
    • Python
    • Agentic loops
    • Tool use
    • System telemetry

  2. 02

    FSK Audio Modem

    Python · DSP · Computer Networks · 2026

    A software-defined modem that sends text through the air as sound — speaker on one end, microphone on the other. No network stack, just physics.

    • Binary frequency-shift keying: 0 → 1200 Hz, 1 → 2200 Hz, with an 800 Hz preamble carrier for synchronisation.
    • Built to explore the physical layer directly rather than read about it — demodulation, framing, and clock recovery all handled in software.
    • Written for a Computer Networks course, then pushed past the assignment.
    • Python
    • Signal processing
    • Modulation
    • Audio I/O

How I work

Three habits that show up in everything above.

i

Diagnose before acting

AEGIS doesn't pick a fix until it has named a root cause, and it re-checks the machine afterward. Same instinct in debugging: the first plausible explanation is usually not the right one.

ii

Go one layer lower

The modem project could have been a socket demo. Doing it in raw tones meant learning what a bit actually looks like when it leaves the machine — that knowledge doesn't expire.

iii

Draw the seams early

Frontend and backend separated from the first commit on Invoice Reader; the object model before the UI on RentLuxFast. Boundaries are cheap up front and expensive later.
