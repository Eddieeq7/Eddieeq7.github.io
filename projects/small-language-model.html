01

What I built

The four parts of a language model. I wrote each one by hand instead of importing a ready-made version.

PART 1 · READ

A tokenizer

Models can't read letters, so text is split into reusable chunks. Mine learns the chunks from the data itself, e.g. " the", " will".

Byte-level BPE, 512-token vocabulary, trained in ~7 s

PART 2 · FOCUS

Attention

For each word, the model decides which earlier words matter most. It can only look backward, never at words that come later.

Causal multi-head self-attention, written out step by step, tested to match PyTorch's built-in version

PART 3 · STACK

The model

Attention plus a small neural network, stacked 4 layers deep, ending in a guess for the next chunk of text.

Decoder-only transformer, 3.29M parameters, 4 layers × 4 heads

PART 4 · LEARN

Training & tuning

The loop that shows it text, measures how wrong its guesses are, and nudges it to improve. Then I tested different settings to see what worked best.

AdamW, warmup + cosine schedule, validation-loss checkpointing, a 10-run sweep

    What it writes (unedited)

    At 3M parameters it learns the shape of a play (names, line breaks, old English) but not real meaning. That's the honest limit at this size.

    Which settings helped? (lower = better, violet = best)

    • Context: more helps, to a point

      Letting it read 32 → 64 → 128 pieces back kept improving it. 256 was worse in the same training time.

    • Bigger model: small gains

      Going wider helped a lot at first, then barely, at 2.2× the size. With only ~1 MB of text, data runs out before size matters.

    • Learning rate: not too slow

      The slowest setting clearly lagged. The fastest was slightly best in this short test.

    The attention code model.py 
    def forward(self, x):
    B, T, C = x.shape
    q, k, v = self.qkv(x).split(C, dim=2)
    # (B, T, C) → (B, heads, T, head_dim)
    q = q.view(B, T, self.n_head, self.head_dim).transpose(1, 2)
    k = k.view(B, T, self.n_head, self.head_dim).transpose(1, 2)
    v = v.view(B, T, self.n_head, self.head_dim).transpose(1, 2)

    att = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_dim)
    att = att.masked_fill(~self.mask[:, :, :T, :T], float("-inf"))  # no peeking ahead
    att = F.softmax(att, dim=-1)                                      # each row sums to 1
    att = self.attn_drop(att)

    y = att @ v                                                       # weighted sum of values
    y = y.transpose(1, 2).contiguous().view(B, T, C)
    return self.resid_drop(self.proj(y))

    What the tests check tests/test_slm.py

    Changing token 10 leaves the outputs at positions 0–9 identical (the causal mask works). Every attention row sums to 1 with zeros above the diagonal. The hand-written attention equals F.scaled_dot_product_attention to 1e-5. The initial loss is ≈ ln(512) (an untrained model is uniform). The model can overfit a single batch to near-zero loss. The tokenizer round-trips ASCII and Unicode exactly.
