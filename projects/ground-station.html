Satellite Telemetry Ground Station.

A C++20 Linux service that receives simulated spacecraft telemetry over UDP, validates every frame against a custom binary protocol with CRC-32, and accounts for every packet that was dropped, duplicated, or delivered out of order, per subsystem. One epoll receive thread feeds worker threads through lock-free single-producer/single-consumer ring buffers.

    Design

    The decisions that shaped the code, and why.

    One ring per worker, sharded by APID

    A single-producer/single-consumer queue needs only one acquire load and one release store per operation: no compare-and-swap loops and no locks. To keep every ring truly SPSC with several workers, the receive thread routes each frame by apid % workers. That gives a second guarantee for free: each subsystem's sequence space belongs to exactly one thread, so the sequence tracker needs no synchronization at all.

    Keeping the hot path off shared cache lines

    Head and tail indices sit on separate cache lines so the producer and consumer don't invalidate each other's line on every operation (false sharing). Each side also keeps a cached copy of the other's index and reloads the real atomic only when the ring looks full or empty. In steady state, most pushes and pops touch no shared memory at all.

    Edge-triggered epoll, drained to EAGAIN

    The socket is non-blocking and registered with EPOLLET, so there's one wakeup per burst instead of one per datagram. The catch with edge-triggering is that you must drain the socket until EAGAIN or you'll never get another edge. On Linux the drain uses recvmmsg to pull up to 64 datagrams per syscall.

    Backpressure is counted, never hidden

    If a worker's ring is full, the receive thread drops the frame and increments ring_full_drops rather than blocking. Blocking would stop the socket drain, and the kernel would then drop packets silently. A dropped packet you can count beats one you never see. (Hit Burst with one slow worker in the demo to watch this happen.)

    The cost of static sharding

    Sharding by apid % workers isn't free. With three subsystems and two workers, worker 1 owns two of them and carries two-thirds of the load, and you can see its ring fill first in the demo. That trade buys lock-free sequence tracking. A real deployment would assign APIDs to workers by measured packet rate rather than by modulo.

    The whole SPSC hot pathspsc_ring.hpp ↗

    // Producer thread only.
bool try_push(T&& v) noexcept {
    const size_t tail = tail_.load(memory_order_relaxed);
    if (tail - head_cache_ > mask_) {
        head_cache_ = head_.load(memory_order_acquire);
        if (tail - head_cache_ > mask_) return false; // full
    }
    slots_[tail & mask_] = std::move(v);
    tail_.store(tail + 1, memory_order_release);
    return true;
}

// Consumer thread only.
std::optional<T> try_pop() noexcept {
    const size_t head = head_.load(memory_order_relaxed);
    if (head == tail_cache_) {
        tail_cache_ = tail_.load(memory_order_acquire);
        if (head == tail_cache_) return std::nullopt;
    }
    T v = std::move(slots_[head & mask_]);
    head_.store(head + 1, memory_order_release);
    return v;
}

    Classifying a sequence number (condensed)sequence_tracker.cpp ↗

    // Signed distance handles uint32 wrap-around.
const int32_t delta = int32_t(seq - highest_);

if (delta > 0) {               // ahead: gap of delta-1 is lost
    clear_skipped_slots(); highest_ = seq; mark(seq);
    stats_.lost += delta - 1;
} else if (delta == 0 || seen(seq)) {
    ++stats_.duplicates;        // already in the window
} else if (-delta < kWindow) {
    mark(seq);                  // late: was counted lost,
    ++stats_.reordered;         // now reclassify it
    --stats_.lost;
}
